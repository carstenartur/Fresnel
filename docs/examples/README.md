# Reproducible Fresnel job examples

These files are user-facing production or experiment inputs for the graphical Fresnel application. Open a `.fresnel` file through **Open job…**; the backend validates and normalizes it through the same canonical job service used by the editor and HTTP API.

## Measurement targets

- [`background-oriented-schlieren-target.fresnel`](background-oriented-schlieren-target.fresnel) — seeded 1920 × 1080 random-dot background with registration border and corner fiducials. Identical parameters produce identical target pixels.

Examples do not contain passwords, tokens, camera addresses, local paths or executable commands.
