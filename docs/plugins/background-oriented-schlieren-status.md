# BOS status

Implemented in the current branch:

- trusted `MEASUREMENT` plugin registration;
- bounded deterministic target parameters;
- spacing-preserving random-dot renderer;
- schema-driven graphical editor;
- browser preview and authoritative PNG export;
- canonical `.fresnel` normalization and example;
- core, backend and browser-level tests;
- truthful capability metadata.

Not yet implemented:

- durable BOS experiment sessions;
- manual or remote capture ingestion;
- displacement-field analysis;
- calibrated result visualization;
- experiment-bundle export.

Those items remain open under issues #139 and #140 rather than being represented by placeholder endpoints or falsely advertised capabilities.
