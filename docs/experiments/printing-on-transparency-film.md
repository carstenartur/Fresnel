# Printing on transparency film

Good print quality usually determines whether the first experiment succeeds.

## Material and printer setup

- Use film that matches printer type (inkjet vs laser).
- Select highest stable quality mode (typically 1200 dpi).
- Disable scaling, fit-to-page, and border auto-adjustment.
- Let prints dry fully before handling or stacking.

## Quick quality checks

1. Print calibration sheet first.
2. Verify 100 mm ruler segment is accurate.
3. Inspect narrow stripe/line fields with a loupe or phone macro photo.
4. Confirm dark zones are dense enough (not gray or porous).

## Common scaling mistakes

- Viewer defaults to “fit”: resulting focal length shifts.
- Driver applies independent X/Y scaling: astigmatic or split focus behavior.
- Incorrect DPI metadata pipeline: printed zone widths mismatch design.
