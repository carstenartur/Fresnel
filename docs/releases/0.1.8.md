# Fresnel 0.1.8 — prepared release notes

**Unpublished candidate.** Source baseline:
`a0dbc55109f3e45ab959633f0482c2b30ea8182f`, compared with
[0.1.7](https://github.com/carstenartur/Fresnel/releases/tag/0.1.7).
The preparation PR also corrects the release metadata handling described below.

## Changes for users and integrators

- A framework-free **measurement-core** module defines bounded capture plans,
  durable session/event records, provider capabilities and portable asset
  metadata. The plugin API distinguishes design and measurement kinds; the
  seven existing plugins remain design plugins. This is the foundation from
  [#142](https://github.com/carstenartur/Fresnel/pull/142), not a completed
  camera-pairing or measurement UI.
- The frontend compatibility updates and dependency checks are consolidated,
  together with merged Maven, browser-test, action and container maintenance.
  The backend now uses Spring Boot 4.1.2.
- Public setup documentation takes user-supplied credentials rather than
  embedding password values
  ([#106](https://github.com/carstenartur/Fresnel/pull/106)).

## Release and distribution reliability

- Release preparation and publication use separate workflows bound to the
  exact candidate commit, with stale-main checks and protected publication.
  JAR/container provenance and checksums refer to the published source.
- Cross-platform package completion is correlated with the immutable release
  tag. Package attachment has its own protected publication step.
- The release version comes from repository metadata. The next development
  version can be selected exactly or by a conventional increment.
- This preparation corrects the missing `measurement-core/pom.xml` entry in
  release and next-SNAPSHOT staging and in both candidate-diff guards. All
  four reactor POMs now participate in the version transition. A regression
  exercises the actual staging commands and guards against disposable Git
  histories; unrelated runtime changes remain rejected.

## Scope and expected assets

The intended tag is **`0.1.8` without a `v` prefix**. The next development
version is `0.1.9-SNAPSHOT`.

Expected distributions follow the existing release contract: the backend JAR
and checksum, Linux tar.gz and Windows ZIP with checksums, plus platform
installers produced by the package workflow. These are planned outputs,
not published downloads.

The open BOS target-generation PRs
[#144](https://github.com/carstenartur/Fresnel/pull/144) and
[#145](https://github.com/carstenartur/Fresnel/pull/145) are outside this
candidate. No completed BOS workflow, remote pairing, camera control or
Photographer integration is claimed.

See [the preparation record](0.1.8-preparation.md) for exact validation
boundaries and the non-publishing rehearsal.
